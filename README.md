# CLI Installer

새 Windows 또는 macOS 컴퓨터에서 AI 코딩 개발 환경을 한 번에 구성하는 설치 도구입니다.

터미널 사용이 익숙하지 않아도 아래 한 줄 명령만 실행하면 개발에 필요한 기본 환경과 AI CLI 도구를 자동으로 설치할 수 있습니다.

지원하는 AI CLI:

- Claude Code
- OpenAI Codex
- Gemini CLI

---

# ✨ Features

CLI Installer는 새 개발 환경에서 반복적으로 필요한 설정을 자동화합니다.

자동 설치 항목:

- Node.js
- npm
- Git
- Python
- Visual Studio Code
- Claude Code
- OpenAI Codex
- Gemini CLI


지원 환경:

- Windows 10 / Windows 11
- macOS (Apple Silicon / Intel)
